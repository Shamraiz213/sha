# CampusDesk — Student & Fee Manager

A responsive, browser-based school administration website built with **HTML, CSS, and vanilla JavaScript**.

## Features
- Student records: add, edit, search, and delete
- Student ID uniqueness checks
- Fee balances and due-date status
- Payment history with receipt IDs, date, purpose, and payment method
- Dashboard summaries for students, fees collected, balances, and overdue students
- Export student records and payment history to CSV
- Full JSON backup and restore
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a modern browser. No build step or external library is required.

## Data and privacy
Records are stored in the browser's localStorage on the current device/browser. This is a lightweight starter app, not a cloud-backed multi-user school system. Browser data can be lost if site data is cleared, so export backups regularly. Do not enter sensitive real student data into a public demo.
